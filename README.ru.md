# Zapekanka

Запекание текстур для игровых ассетов в Blender 4.2+: high → low с автоматическим кажем, разнесённое
запекание, суперсэмплинг, PBR в одну кнопку, пресеты движков, запекание в фоне и экспорт в Unreal Engine,
Unity, Godot, Substance 3D Painter, Marmoset Toolbag, glTF и Roblox.

[English version](README.md). Там же подробные таблицы карт, пресетов и инструкции по экспорту.

## Возможности

- **Пары high/low** по суффиксам (`Gun_low`, `Gun_high`, `Gun_high_bolt`, `Gun_cage`) или по коллекциям
  (`Gun_low`, `Gun_high`). Вся сцена запекается одной кнопкой; несколько пар можно запечь в один
  текстурный сет (атлас).
- **Авто-каж**: временная копия low, выдавленная по усреднённым нормалям, с равномерной толщиной на жёстких
  рёбрах. Экструзия общая или своя для пары, превью сеткой, кнопка автоподбора. Дистанция лучей авто
  (2× экструзия) или вручную. Поддерживается и свой каж.
- **Карты**: Normal (OpenGL / DirectX), AO, Curvature, Thickness, Position, World Normal, Height, ID Color
  (по материалу, объекту, островку меша или цвету вершин).
- **PBR в одну кнопку**: Base Color, Roughness, Metallic, Normal, AO, Emission, Opacity из материалов high.
  Материалы конвертируются в emission-копии (Principled и другие BSDF, группы нод, подключённые входы),
  поэтому освещение в текстуры не попадает.
- **Цветовые пространства**: Base Color и Emission всегда sRGB, Normal / Roughness / Metallic / AO / ORM и все
  карты меша всегда Non-Color, в том числе при импорте в материал.
- **Упаковка**: ORM (R = AO, G = Roughness, B = Metallic) для UE5, Godot, glTF; Metallic + Smoothness для Unity;
  Mask Map для HDRP; Opacity в альфе Base Color.
- **Разнесённое запекание**: пары разносятся по оси на время запекания, AO и лучи не заливают соседей.
- **Суперсэмплинг** 2× / 4× / 8× с правильным даунскейлом (нормали перенормализуются); большие запекания
  автоматически делятся на тайлы, 8K × 4× помещается в память.
- **Паддинг** без швов (Adjacent Faces) и заливка всей текстуры (нет швов на мипмапах).
- **Проверка перед запеканием**: масштаб, отрицательный масштаб, нет UV, перекрытие/складки UV, перекрытие UV
  между объектами одного сета, перевёрнутые нормали, non-manifold, дубли вершин, кастомные нормали,
  нетриангулированный low, несохранённые или пропавшие картинки. Исправление в один клик.
- **Пресеты**: UE5, Unity URP/HDRP, Godot 4, Roblox, glTF, Substance 3D Painter, Marmoset: DX/GL, имена
  (`T_Name_BC`, `T_Name_ORM` …), упаковка, формат файлов.
- **Недеструктивность**: запекание идёт в отдельной сцене на дубликатах. Объекты, меши, материалы и настройки
  рендера пользователя не меняются, всё временное удаляется даже при ошибке.
- **Запекание в фоне**: отдельный процесс `blender --background`, интерфейс не виснет; прогресс, отмена,
  очередь.
- **Авто-материал**: после запекания создаётся и назначается материал со всеми подключёнными текстурами.
  Исходные материалы можно вернуть.
- **Экспорт**: Unreal (вживую в открытый редактор или скриптом импорта), Unity (editor-скрипт сам настраивает
  импорт и материалы), Godot (glb + `ORMMaterial3D`), Substance / Marmoset (совпадающие имена low/high/cage),
  glTF / Sketchfab, Roblox.

## Установка

1. Скачайте `zapekanka-<версия>.zip` (Releases или артефакт `zapekanka-extension` сборки CI).
2. Blender: **Edit > Preferences > Get Extensions > ⌄ > Install from Disk**.
3. Панель: 3D-вьюпорт, боковая панель (**N**), вкладка **Zapekanka**. При русском языке Blender интерфейс
   аддона тоже на русском.

Собрать zip самому: `python tools/build.py`.

## Быстрый старт

1. Назовите объекты `Имя_low` / `Имя_high` (или разложите по коллекциям `Имя_low` / `Имя_high`). У low
   должна быть UV-развёртка.
2. Выберите пресет (например, *Unreal Engine 5*) и набор карт (**Полный PBR**, **Игровой**, **Карты меша**).
3. В **Вывод и качество** укажите папку и разрешение (для относительного пути `//textures/` сохраните .blend).
4. **Найти пары** → **Запечь всё**. Сначала выполняется проверка, при ошибках запекание не стартует.
5. Текстуры в папке, материал на low. **Экспорт** отправляет ассет в движок.

## Unreal Engine: отправка вживую

1. В Unreal включите **Python Editor Script Plugin**.
2. **Project Settings > Plugins > Python > Enable Remote Execution**.
3. Multicast-группа, порт и bind-адрес в настройках аддона должны совпадать с Unreal (по умолчанию
   `239.0.0.1`, `6766`, `127.0.0.1`).

Если редактор не ответил, в папке экспорта остаётся `import_to_unreal.py`: **Tools > Execute Python Script**.

## Если что-то не так

- **«N% текселей не получили лучей»**: каж не охватывает high. Увеличьте экструзию (или **Подобрать
  экструзию**) либо дистанцию лучей.
- **Швы нормалей в движке**: экспортируйте low триангулированным; если движок триангулирует иначе, включите
  **Триангулировать low**.
- **AO от соседних деталей**: включите **Разнесённое запекание** и разнесите детали по разным парам.
- **Фоновое запекание упало**: кнопка **Открыть лог**.

## Разработка

```
pip install bpy==5.2.*         # или 4.2.* / 4.5.* на Python 3.11
python tests/run.py            # все тесты (реальное запекание в Cycles)
python tools/build.py          # dist/zapekanka-<версия>.zip
```
